# Actors API

A small Rust REST API built with Axum. It connects to PostgreSQL and returns actor records as JSON.

## Requirements

- Rust and Cargo (edition 2024)
- PostgreSQL

## Database setup

Create a PostgreSQL database, then create the table the API reads from:

```sql
CREATE TABLE actor (
    actor_id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    first_name TEXT NOT NULL,
    last_name TEXT NOT NULL,
    birth_date DATE,
    created_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
```

Add any actor records you want returned. For example:

```sql
INSERT INTO actor (first_name, last_name, birth_date)
VALUES ('Jane', 'Doe', '1985-04-12');
```

## Configure the connection

Create a `.env` file in the project root and set `DATABASE_URL` to your PostgreSQL connection string:

```env
DATABASE_URL=postgres://USER:PASSWORD@localhost:5432/DATABASE_NAME
```

Replace `USER`, `PASSWORD`, and `DATABASE_NAME` with your local PostgreSQL credentials and database name. Keep `.env` private; do not commit credentials to GitHub.

## Run the API

From the project directory, run:

```sh
cargo run
```

The server listens at `http://127.0.0.1:3000`.

## API

### Get all actors

```http
GET http://127.0.0.1:3000/actors
```

Example response:

```json
[
  {
    "actor_id": 1,
    "first_name": "Jane",
    "last_name": "Doe",
    "birth_date": "1985-04-12",
    "created_at": "2026-10-11 12:00:00+00"
  }
]
```

The `birth_date` and `created_at` values may be `null` when the corresponding database values are null. The endpoint returns an empty array when the table has no records.
